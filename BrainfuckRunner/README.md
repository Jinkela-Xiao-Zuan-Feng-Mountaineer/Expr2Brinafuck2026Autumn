# Brainfuck 執行器

執行作業規格的 Brainfuck 工具。

## Brainfuck 規格

- 輸入與輸出都是讀取 int ，並儲存成 uint8 的型態
- 具有 1048576 的陣列空間，初始話位置在 0

支援 Brainfuck 語法

- `>` 指標加一
- `<` 指標減一
- `+` 指標所指位元組的值加一
- `-` 指標所指位元組的值減一
- `.` 輸出指標所指位元組內容 (uint8) stdout
- `,` 向指標所指的位元組輸入內容（uint8）stdin
- `[` 若指標所指位元組的值為零，則向後跳轉，跳轉到其對應的`]`的下一個指令處
- `]` 若指標所指位元組的值不為零，則向前跳轉，跳轉到其對應的`[`的下一個指令處

## 編譯與執行

需要支援 C++20 的 C++ 編譯器與 GNU Make。

```sh
make
./bf input.bf
./bf input.bf 1000000
```

第三行示範最多執行 1,000,000 個指令；省略 `maxstep` 參數時時無上限。

結果寫入 `output.txt`，執行次數或錯誤訊息仍會顯示在終端機。

### maxstep

用法：`./bf input.bf [maxstep]`。

`maxstep` 接受一個十進位非負整數，表示能執行指令次數的最大上限，恰好執行完指定步數仍可成功。若還有下一個指令，會在執行該指令前中斷，向 stderr 回報 `maxstep exceeded`、上限、已執行步數及行列位置，並回傳 `-1`。已產生的輸出會保留。

## 執行規則

- 記憶體固定為 1,048,576 個 uint8 記憶格，初始值全部為 0，指標初始位置為 0。
- 加減與輸入轉換皆以 mod 256 運作。例如輸入 `-1` 儲存為 255，輸入 `256` 儲存為 0。
- `,` 從 stdin 讀取一個空白分隔的十進位 `int`，可含正負號。輸入耗盡、非整數或超出 C++ `int` 範圍皆報錯。
- `.` 向 stdout 輸出目前記憶格的十進位整數（0–255），每筆一行。
- 除 `><+-.,[]` 外，所有字元皆忽略。註解中的這八個字元仍會被當成指令。
- 執行前檢查整份程式的括號配對，包含不會執行的區段。
- `[` 遇到 0 時跳至對應 `]` 的下一指令；`]` 遇到非 0 時跳至對應 `[` 的下一指令。
- 成功時回傳 0，stderr 輸出 `Executed instructions: N`。僅計算實際執行的指令，包括執行到的括號；忽略字元和被跳過的指令不計數。例如 `+++[-].` 為 11 次。
- 失敗時回傳 `-1`，stderr 輸出錯誤資訊。
- 執行步數的上限由可選的 `maxstep` 參數設定。
